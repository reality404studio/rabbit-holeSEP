# 1단계 — 분류 체계 만들기

**입력**: `map/entries-all.txt` (1,859줄, 첨부)
**출력**: `map/fields.json` 하나
**실행**: 대화 한 번. 파일을 첨부하고 아래를 그대로 붙여넣는다.

---

당신은 스탠퍼드 철학백과사전(SEP)의 전체 항목 목록을 받았습니다. 1,859개이고
각 줄은 `slug :: title` 입니다.

이 목록으로 **두 층짜리 지도**를 만듭니다. 이 지도는 나중에 "사용자의 질문이
어느 갈래로 읽히는가"를 정하는 데 쓰입니다. 목록을 다시 출력하는 일이
아니라, 이 코퍼스가 **실제로 어떻게 뭉치는지** 관찰해서 좌표계를 만드는 일입니다.

## 1층 — 분야 (fields)

목록 전체를 덮는 30~45개의 분야. 모든 항목이 정확히 하나의 분야를 주소로 갖게 됩니다.

**하지 말아야 할 것 — 이게 이 작업의 핵심 제약입니다.**

"형이상학 / 인식론 / 윤리학 / 논리학 / 심리철학 / 과학철학 / 정치철학"
같은 **표준 학부 분과 목록을 옮겨 적지 마세요.** 그것은 '철학 분류'라는
개념의 평균이고, 어느 코퍼스에 붙여도 똑같이 나오는 답입니다. 그런 목록을
쓰면 이 목록을 읽은 의미가 없습니다.

대신 **이 목록에만 있는 뭉침**을 보세요. SEP는 실제로:
- 특정 인물에 항목 하나씩 붙은 거대한 인명 덩어리가 있고
- 아랍·중국·인도·유대 전통이 각각 독립된 계열을 이루고 있고
- 중세 논리학처럼 현대 분과와 안 맞는 단위가 있고
- 특정 문제 하나에 십수 개 항목이 달라붙은 지점들이 있습니다

분야는 **크기가 고르지 않아도 됩니다.** 다만 한 분야가 120개를 넘을 것 같으면
쪼개세요. 나중에 이 분야 단위로 후보를 꺼낼 것이라, 너무 크면 쓸모가 없습니다.

분야마다:
- `id` — 영문 소문자·하이픈
- `ko` — 한국어 이름
- `scope` — 이 분야가 다루는 문제의 범위, 한 문장. "무엇에 대한 항목들인가"
- `arrivals` — **일반인이 이 분야에 도착하게 되는 질문 2~3개.** 학술 용어를
  쓰지 말고 실제로 사람이 던질 법한 문장으로. (예: "기계가 생각할 수 있나")

`arrivals`가 런타임에서 가장 중요하게 쓰입니다. 분야 이름이 아니라 이 문장들이
사용자의 질문과 대조됩니다.

## 2층 — 문제축 (axes)

분야를 **가로지르는** 반복 문제 12~20개.

분야는 항목을 갈라놓지만, 문제축은 **멀리 떨어진 분야의 항목 둘을 묶습니다.**
이게 이 지도를 만드는 진짜 이유입니다 — 같은 분야 안의 연결은 뻔하고,
서로 다른 분야가 같은 문제축을 공유할 때 의외의 연결이 나옵니다.

좋은 문제축의 조건: **최소 세 개의 서로 다른 분야에 걸쳐야 합니다.**
한 분야 안에서만 나타나는 것은 축이 아니라 그냥 그 분야의 하위 주제입니다.

축마다 `id`, `ko`, `gloss`(한 문장), 그리고 `spans` — 이 축이 걸치는 분야 id 3개 이상.

## 출력 형식

JSON 하나만. 설명·서문·후기 없이 코드블록 하나로.

```json
{
  "fields": [
    {
      "id": "mind",
      "ko": "마음의 본성",
      "scope": "무엇이 마음을 마음이게 하는가 — 심적 상태의 본성과 물리적 기반",
      "arrivals": ["기계가 생각할 수 있나", "감정은 일종의 판단인가"]
    }
  ],
  "axes": [
    {
      "id": "normativity-source",
      "ko": "규범의 근거",
      "gloss": "어떤 것이 왜 마땅한가 — 사실에서 당위로 넘어가는 지점",
      "spans": ["ethics-normative", "action", "law-phil", "logic-phil"]
    }
  ]
}
```

## 마지막

JSON 뒤에 **짧게** 덧붙이세요:
- 분류하기 어려웠던 지점 2~3개와 그 이유
- 표준 분과 목록을 쓰지 않으려다 무리한 부분이 있다면 어디인지

이건 지도의 신뢰도를 재는 데 씁니다. 잘 된 척하지 마세요.
