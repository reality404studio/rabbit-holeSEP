# 2단계 — 항목 배정

**입력**: 1단계에서 나온 `fields.json` + `map/batches/NN.txt` 한 개
**출력**: JSONL. 한 줄이 한 항목
**실행**: 배치마다 **새 대화**로. 10번 반복 (01~10)

새 대화로 하는 이유 — 긴 대화에서는 앞 배치의 판단이 뒤 배치를 오염시킵니다.
분류 체계를 매번 다시 붙여넣는 비용이 그것보다 쌉니다.

---

아래는 스탠퍼드 철학백과사전(SEP)의 분류 체계입니다.

```json
[여기에 1단계에서 나온 fields.json 전체를 붙여넣으세요]
```

그리고 아래는 SEP 항목 186개입니다. 각 줄은 `slug :: title` 입니다.

```
[여기에 map/batches/NN.txt 내용을 붙여넣으세요]
```

각 항목을 위 분류 체계에 배정하세요.

## 배정 규칙

- `f` — 주 분야 id **정확히 하나.** 위 체계에 있는 id만. 새로 만들지 마세요
- `f2` — 부 분야 id **0~2개.** 이 항목이 다른 분야에서 찾아질 법하면 넣으세요
- `ax` — 문제축 id **0~3개.** 억지로 채우지 마세요. 해당 없으면 빈 배열
- `g` — **제목만 보고 무슨 항목인지 모르는 경우에만** 15자 이내 한국어 설명.
  제목이 이미 명백하면(`abduction`, `free will`) **빈 문자열로 두세요.**
  출력 분량을 줄이려는 게 아니라, 안 써도 되는 곳에 쓰면 지어내게 되기 때문입니다
- `c` — 확신도 `h`(높음) / `m`(보통) / `l`(낮음)

## 지어내지 마세요 — 이게 가장 중요합니다

이 목록에는 당신이 내용을 모르는 항목이 반드시 있습니다. 특히 인명 항목,
비서구 전통, 중세 인물, 제목이 도치되어 잘린 것들(`atomism-modern :: 17th to
20th century` 같은)이 그렇습니다.

**모를 때 그럴듯한 설명을 쓰지 마세요.** `c`를 `l`로 두고 `g`는 비우고,
제목에서 확실히 읽히는 만큼만 배정하세요. 나중에 `l` 표시된 것만 따로 검토합니다.
확신도를 부풀리면 지도 전체를 못 믿게 되고, 그러면 이 작업이 통째로 무의미해집니다.

## 출력 형식

JSONL 하나. 입력 순서 그대로, **186줄 전부.** 코드블록 하나에.
설명·서문·요약·"이하 생략" 금지. 줄이 빠지면 그 항목은 지도에서 사라집니다.

```
{"slug":"functionalism","f":"mind","f2":["ai","science-phil"],"ax":["mind-body","levels"],"g":"","c":"h"}
{"slug":"atomism-modern","f":"metaphysics-history","f2":[],"ax":["matter-structure"],"g":"근대 원자론사","c":"l"}
```

마지막에 **한 줄만** 덧붙이세요: `확신도 낮음(l) N개 / 186개`
